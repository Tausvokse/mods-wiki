# UniCrates Documentation

Welcome to the official documentation for **UniCrates**!

The ultimate crate plugin for Cobblemon, Fabric, and NeoForge.

## Features
- **Multi-Platform**: Works on both Fabric and NeoForge natively.
- **Fully Customizable**: Highly configurable crates, rewards, animations, and limits.
- **Developer Friendly**: Easy to extend and build upon with our comprehensive API.
