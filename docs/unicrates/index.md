## Lite: four free tier families

Common, Rare, Epic and Legendary each include a matching key, model and opening timeline. Configure item, command, experience and broadcast rewards in JSON. Preview rewards before opening. Player data uses JSON storage. Cobblemon, a Pro license and an activation service are not required.

Use one shared server/client JAR per loader, or the server-only variant with a hosted required resource pack. Fresh defaults allow normal players to preview and open crates without OP. Existing configuration files retain their permission settings.

On a player's first successful join to each Lite server, a single chat notice identifies Pro as a separate paid edition and links to its details. The flag is saved with player data; server-only waits for its resource pack to load.

## Pro: custom content and additional server features

Pro adds additional built-in models, custom models and timelines, browser/in-game editors, additional reward integrations and SQL storage. It requires a registered server license and online activation. Optional integrations need compatible dependencies. Server-only and companion-client rendering have different capabilities; read the installation guide.

The detailed model, animation and advanced configuration reference pages cover the broader engine and Pro features. Their historical 2.3 examples do not expand the Lite feature set. Use the 3.x edition and installation pages for current distributions and licensing.
