# Permissions

Besides command-level permissions (which are level 2 OP by default or LuckPerms nodes), you can restrict crate opening and previewing in the Crate config:

- \
estrictions.requiredPermission\: Players need this permission to open the crate.
- \preview.requirePermissionToPreview\: If true, players need \unicrates.crate.&lt;id&gt;.preview\ to view the preview GUI.
