# Gameplay

## Getting Crates & Keys
Server admins can give physical crate blocks, portable crate items, or keys (physical/virtual) using commands (\/crate give\, \/crate key give\).

## Placing & Removing
Admins look at a block and type \/crate create &lt;id&gt;\ to place a crate anchor. Removing is done via \/crate remove\.

## Opening Crates
Players interact with the crate block. Right-clicking with a key (or if virtual keys are available) triggers the opening sequence. Players can also 'Mass Open' multiple keys at once via the \/crate massopen\ command.

## Previewing
Right-clicking the crate empty-handed or using \/crate preview\ opens the reward preview GUI (permission node may apply). The GUI shows rarity tiers, win chance percentages, and daily limits.
